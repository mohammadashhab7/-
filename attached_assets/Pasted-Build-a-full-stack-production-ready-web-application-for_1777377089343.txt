Build a full-stack, production-ready web application for an Arabic sweets business called "الدمشقي".

This is NOT a simple website. This is a complete ERP + E-commerce + POS + Manufacturing Management System.

---

## GENERAL REQUIREMENTS

* Language: Arabic (RTL support بالكامل)
* Architecture: Full-stack (Frontend + Backend + Database)
* Use a real database (PostgreSQL preferred)
* Build clean REST API or modular backend structure
* No mock data – real data handling only
* Scalable and modular codebase
* Clean UI + professional UX

---

## CORE MODULES

1. PRODUCT MANAGEMENT SYSTEM (TWO-LAYER)

A) Production (المشغل)

* Raw materials management (materials CRUD)
* Recipes system (define ingredients per product)
* Production orders:

  * Input: raw materials
  * Output: finished products
* Auto cost calculation per product

B) Store / Exhibition (المعرض)

* Receive products from production
* Inventory management (stock tracking)
* Product availability for sale

IMPORTANT:

* Internal transfer system:
  Production → Store
* Deduct materials on production
* Increase finished goods stock
